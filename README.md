#### 🏥 Zero-Trust Clinical EHR Assistant
> A privacy-first RAG system that lets clinicians query Electronic Health Records in plain language, without exposing patient data to the LLM.

- **Problem:** Clinical records are hard to search, and sending patient data to an external LLM is a serious privacy risk.
- **Solution:** Semantic search over the MIMIC-IV dataset with pgvector and BioClinical ModernBERT embeddings. Microsoft Presidio masks all PHI/PII before the LLM sees it, NVIDIA NeMo Guardrails block medical advice and diagnoses, and each chat session is locked to one patient.
- **Role:** Built it on my own: data ingestion, embedding pipeline, redaction, guardrails, FastAPI backend and Streamlit UI.
